# SORLEEX MART Sales Performance Analysis Using Power BI

## Project Overview

This project focuses on analyzing SORLEEX MART's sales performance using **Microsoft Power BI** to uncover meaningful insights into revenue generation, order distribution, product category performance, delivery operations, and order statuses.

The objective was to transform raw sales data into an interactive business intelligence dashboard that enables stakeholders to monitor sales performance, track order fulfillment, identify operational trends, and make informed business decisions.

Using Power BI, I developed an interactive dashboard featuring key performance indicators (KPIs), data visualizations, and slicers that allow users to explore performance across different years, months, product categories, and locations.

## Introduction

Businesses need reliable information about their sales performance to understand how revenue is generated, which locations contribute the most, and how efficiently customer orders are processed and delivered.

Without proper sales monitoring, businesses may struggle to identify underperforming locations, track returned orders, monitor pending deliveries, and understand product category contributions.

This project uses Microsoft Power BI to analyze SORLEEX MART's sales data and present important business metrics through an interactive dashboard.

The analysis focuses on answering questions such as:

* How much revenue has the business generated?
* How many orders have been recorded?
* How are orders distributed across different statuses?
* Which locations generate the highest revenue?
* Which product categories contribute to processed orders?
* How do returned and delivered orders vary across months?
* Which locations have the highest number of pending orders?

The dashboard provides a centralized view of these metrics to support effective business monitoring and decision-making.

## Project Objectives

The major objectives of this project are to:

1. Monitor overall sales performance using key performance indicators.

## Dashboard Overview

The dashboard consists of interactive visualizations designed to provide a comprehensive overview of SORLEEX MART's sales and operational performance.

### 1. Key Performance Indicators (KPIs)

The dashboard contains five KPI cards:

| KPI              | Displayed Value |
| ---------------- | --------------: |
| Total Revenue    |             ₦6M |
| Total Orders     |              1K |
| Returned Orders  |             174 |
| Delivered Orders |             167 |
| Pending Orders   |             162 |

These indicators provide a quick overview of the company's revenue, order volume, and order fulfillment performance.

### 2. Revenue by Location

**Visualization:** Area/Line Chart

This visualization compares revenue generated across different business locations.

| Location      | Revenue |
| ------------- | ------: |
| Port Harcourt |  ₦0.84M |
| Kano          |  ₦0.74M |
| Ibadan        |  ₦0.74M |
| Lagos         |  ₦0.73M |
| Enugu         |  ₦0.70M |
| Benin City    |  ₦0.69M |
| Abuja         |  ₦0.67M |
| Ilorin        |  ₦0.64M |

**Insight:**
Port Harcourt recorded the highest revenue at approximately ₦0.84M, while Ilorin recorded the lowest at approximately ₦0.64M.

This comparison helps management identify stronger-performing markets and locations that may require additional sales attention.

### 3. Revenue by Status

**Visualization:** Doughnut Chart

This chart illustrates the percentage distribution of revenue across six order statuses.

| Order Status | Revenue Share |
| ------------ | ------------: |
| Cancelled    |        18.02% |
| Delivered    |        17.02% |
| Pending      |        16.84% |
| Returned     |        16.36% |
| Shipped      |        16.07% |
| Processing   |        15.68% |

**Insight:**
Cancelled orders account for the largest share at 18.02%, while processing orders account for the smallest share at 15.68%.

The distribution highlights the need for management to investigate cancelled and returned transactions and improve the overall order fulfillment process.

### 4. Returned Orders by Month

**Visualization:** Column Chart

This chart examines the number of returned orders across different months.

| Month     | Returned Orders |
| --------- | --------------: |
| July      |              18 |
| May       |              16 |
| April     |              15 |
| January   |              15 |
| March     |              11 |
| September |              11 |

**Insight:**
July recorded the highest number of returned orders, with 18 transactions, while March and September recorded the lowest, with 11 each.

This information can help management investigate possible reasons for product returns and identify opportunities to improve customer satisfaction.

### 5. Delivered Orders by Month

**Visualization:** Horizontal Bar Chart

This visualization compares the number of successfully delivered orders across different months.

| Month     | Delivered Orders |
| --------- | ---------------: |
| January   |               20 |
| April     |               19 |
| July      |               18 |
| September |               17 |
| March     |               16 |
| May       |               16 |

**Insight:**
January recorded the highest number of delivered orders, with 20 transactions, followed by April with 19.

March and May recorded the lowest delivery figures, with 16 orders each.

Monitoring these monthly variations can help management evaluate delivery performance and identify areas requiring operational improvement.

### 6. Processed Orders by Category

**Visualization:** Doughnut Chart

This chart presents the distribution of processed orders across six product categories.

| Product Category | Distribution |
| ---------------- | -----------: |
| Books            |       21.56% |
| Beauty           |       17.96% |
| Fashion          |       17.37% |
| Home & Kitchen   |       16.17% |

**Insight:**
Books account for the largest share of processed orders at 21.56%, while Electronics account for the smallest share at 10.78%.

This provides an overview of category-level order distribution and helps management understand customer purchasing activity across product categories.

### 7. Pending Orders by Location

**Visualization:** Column Chart

| Location      | Pending Orders |

## Interactive Features

The dashboard includes four slicers that allow users to filter and explore the data dynamically.

| Slicer           | Purpose                                       |
| ---------------- | --------------------------------------------- |
| Year             | Filter sales performance by year              |
| Month Name       | Analyze performance for selected months       |
| Product Category | Examine performance across product categories |
| Location         | Compare sales performance across locations    |

These interactive filters make it easier for stakeholders to investigate specific business segments and understand how different factors influence overall performance.

## Key Business Insights

Based on the dashboard analysis, the following observations were identified:

1. **Revenue Performance:** The business generated approximately ₦6M in total revenue, with Port Harcourt contributing the highest location-level revenue.

2. **Order Management:** The dashboard recorded 174 returned orders, 167 delivered orders, and 162 pending orders.

3. **Order Status Distribution:** Cancelled orders represent the largest share of revenue by order status, highlighting an area that requires further investigation.

4. **Monthly Returns:** July recorded the highest number of returned orders, suggesting the need to investigate possible causes of product returns.

5. **Product Category Performance:** Books recorded the highest share of processed orders, while Electronics recorded the lowest.

6. **Pending Orders:** Ilorin recorded the highest number of pending orders, indicating a possible opportunity to improve order fulfillment in that location.

---

## Business Recommendations

Based on the findings, the following recommendations are proposed:

* **Improve Order Management:** Investigate the reasons behind cancelled and returned orders to reduce potential revenue losses.

* **Strengthen Delivery Operations:** Monitor locations with higher pending orders and improve delivery coordination.

* **Review Product Returns:** Investigate why July recorded the highest number of returned orders and implement measures to reduce future returns.

* **Optimize Product Category Performance:** Evaluate customer demand across product categories and develop strategies to improve underperforming categories.

* **Monitor Location Performance:** Study the factors contributing to Port Harcourt's stronger revenue performance and identify opportunities to improve sales in other locations.

* **Use Data for Continuous Monitoring:** Regularly monitor the dashboard to identify changes in sales performance, order distribution, and delivery efficiency.
